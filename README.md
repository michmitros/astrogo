# astrogo

A Go library for working with astronomical data.

> **Status:** the project is in an early stage of development. The API may change.

## Modules

- [`fits`](fits/README.md) – reading FITS files (headers, data, image conversion to grayscale).

## Installation

```bash
go get github.com/michmitros/astrogo
```
